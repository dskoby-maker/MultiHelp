# MultiHelp.es

Каталог мастеров и специалистов в Испании: сантехники, видеографы, тренеры, мастера маникюра и др.
Клиенты пишут мастерам напрямую в WhatsApp, без комиссий. Размещение на время запуска бесплатное.

- Сайт: **multihelp.es** (Тильда, блок HTML грузит файл `app.js` — см. `tilda-block.html`)
- Версия-приложение для телефона: **dskoby-maker.github.io/MultiHelp**
- Мастера заполняют анкету (Google Формы на ES / RU / EN) → ответы попадают в Google Таблицу «MultiHelp — мастера» →
  одобренные (галочка «Показывать») публикуются на вкладке «Сайт» как CSV → сайт читает этот CSV.

Код сайта — `app.js`. Настройки (ссылка на CSV, анкеты, WhatsApp) — в самом начале `app.js`, блок `window.MULTIHELP`.
