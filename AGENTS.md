# Инструкция для ИИ-агента

Пиши Даниилу **по-русски**, просто, по шагам, без технических терминов. Программировать он не умеет:
не проси «поправить строчку», делай правку сам и пиши, что проверить.

## Что это
MultiHelp.es — каталог мастеров в Испании (Аликанте и др.). Интерфейс на трёх языках: ES (по умолчанию) / RU / EN — язык берётся из телефона, есть переключатель (сохраняется в `mh_lang`).

## Как устроено
- **Исходник — `dev/src/site.html`**, словарь переводов — объект `I18N` внутри него (копия в `dev/i18n_dict.js`).
  Сборка: `python3 dev/build_from_single_html.py <версия>` → обновляет `app.js` и `index.html`. Новые тексты добавлять во все три языка.
- `app.js` — весь сайт (стили, разметка, логика) в одном файле. Сам вставляет себя в `<div id="mh-root">`.
- `index.html` — страница для GitHub Pages (приложение на телефоне), грузит `app.js?v=…` (меняй `v` при каждом выпуске).
- `tilda-block.html` — что вставлено в блок HTML на Тильде (multihelp.es). Тильду при правках трогать не нужно.
- Данные мастеров — опубликованная CSV вкладки «Сайт» Google Таблицы. Столбцы узнаются по ключевым словам заголовков
  (ES/RU), см. `FIELDS` в `app.js`. Без ссылки на CSV сайт показывает демо-мастеров с меткой «демо».
- Анкеты и таблица создаются скриптом `dev/multihelp-setup.gs` (Google Apps Script).
- Личные кабинеты мастеров — Supabase (вход по почте с кодом / Google, объявления, фото). Включаются, когда в
  `window.MULTIHELP` заполнены `SUPABASE_URL` и `SUPABASE_KEY`. База создаётся скриптом `dev/supabase-setup.sql`
  (Supabase → SQL Editor). Объявления из кабинета показываются на сайте вместе с мастерами из таблицы;
  ссылка на объявление — `multihelp.es/?m=<id>`. Администраторы — таблица `admins`.
- Чат клиента с мастером (только для объявлений из кабинета), жалобы и блокировка — `dev/supabase-chat.sql`.
  WhatsApp и звонок показывают окно с советами по безопасности.
- Приложение на телефоне (PWA) — версия на GitHub Pages (`APP_URL`): `sw.js` (собирается из `dev/src/sw.js`),
  `manifest.webmanifest`, кнопка «Установить приложение». Уведомления о сообщениях: таблица `push_subs` и
  вызов функции из `dev/supabase-push.sql`, сама рассылка — Edge Function `dev/supabase/functions/notify/index.ts`
  (секреты VAPID_PUBLIC / VAPID_PRIVATE хранятся в Supabase, в репозиторий не кладутся).

## Правила
- Не выдумывать рейтинги и отзывы для реальных мастеров (запрещено в ЕС).
- После правки проверить сайт на телефоне (390×844) и на ПК, без ошибок в консоли.
